# Line Editor - Help

## 1. Insert Line

Inserts a new line at the given line number.

### Usage

Choose option:

1. Insert line

Then enter the line number and text.

### Example

Enter your choice: 1
Enter line number: 1
Enter text: Hello World

Output:

Line inserted successfully.

---

## 2. Delete Line

Deletes a line from the document using its line number.

### Usage

Choose option:
2. Delete line

Then enter the line number to delete.

### Example

Enter your choice: 2
Enter line number to delete: 1

Output:

Line deleted successfully.

---

## 3. Display Document

Displays all lines currently stored in the document with their line numbers.

### Usage

Choose option:
3. Display document

### Example

Enter your choice: 3

Output:

--- Document ---
1: Hello World

---

## 4. Exit

Closes the Line Editor program.

### Usage

Choose option:
4. Exit

### Example

Enter your choice: 4

Output:

Exiting Line Editor...
